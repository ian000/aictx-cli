# Sub-agent 条件分工规则

仅当当前 AI 工具提供 sub-agent、parallel agent 或等价能力，并且分工收益高于协调成本时，才使用该能力。

## 适合分工的任务

满足以下任一条件时，可以直接分工，无需额外询问用户：

- 可以拆分为多个彼此独立、没有前置依赖的子任务。
- 子任务职责明确分离，合并处理会污染 context 或降低判断质量。
- 存在大量结构相同的重复工作，适合批量并行处理。
- 子任务需要不同的 model、工具或 sandbox 权限，并且当前宿主支持这些配置。

## 不应分工的任务

- 任务简单、范围很小或单个执行者可以快速完成。
- 子任务紧密耦合、存在连续依赖，或会同时修改相同文件。
- 分工、等待和整合的成本预计高于直接完成任务。
- 当前 AI 工具不支持可靠的 sub-agent 能力。

## 执行约束

- 每个子任务必须具体、有边界、可独立验证，避免职责重叠。
- 无依赖任务并行执行；有依赖任务按顺序执行。
- 主智能体负责整合结果、解决冲突并执行最终验证，不能直接把未经复核的子任务结果当作完成结果。
- 面向用户只汇总最终结果和必要阻碍，不逐份粘贴 sub-agent 的过程报告。
- 如果宿主不支持 sub-agent，直接在当前智能体内完成，不把工具能力限制转化为无必要的用户沟通。
