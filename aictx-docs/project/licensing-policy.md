# Licensing Policy

## Decision

从下一次发布开始，aictx 使用 `PolyForm-Noncommercial-1.0.0`，允许非商业目的使用、修改和分发。任何商业用途都需要从项目作者获得单独的书面授权。

由于许可证限制商业使用，项目应称为 **Source-Available**，不再称为 OSI Open Source。

## Historical Releases

已经以 MIT 发布的历史版本继续适用其发布时的 MIT 条款。新的许可证不能追溯撤销已经授予的权利。

## Commercial Authorization

商业使用者应通过项目 GitHub 仓库联系作者，并在获得书面商业授权后使用当前版本。

## Scope Note

PolyForm Noncommercial 也允许慈善机构、教育机构、公共研究机构和政府机构等非商业组织使用。如果未来需要收紧为“仅自然人个人学习”，应请专业律师起草定制条款，不直接修改 PolyForm 标准文本。
